# Agent2LLM · AI 执行方案与证据工作台

面向 AI 产品经理 / 解决方案岗位的项目案例。

使用场景：开发者或解决方案人员需要把大目标拆成执行步骤，交给工具处理，并判断结果是否达标。原项目已有 CLI 与多适配器能力；桌面版降低启动与连接门槛。

产品决策：先由模型输出有验收条件的步骤，用户审阅后才修改项目。桌面初版只集成 Codex 执行器，保留现有 CLI 的多适配器能力。执行结束与业务验收分开呈现；没有读取到测试数量时保持未知。

技术与取舍：官方 ChatGPT 授权由主进程处理，执行器收到当前步骤及验收条件。新增 `a2l compare` 只比较目标相同、结束且有成功回执与测试证据的运行。输入字节数是传递量，不能充当真实 Token 计费或节省比例。

已验证：桌面窗口、页面隔离、未登录阻断、固定示例标识；CLI 比较拒绝不完整证据。真实账户下的 AI 生成与项目执行尚需完成，不能用模拟测试代替。

演示路线：打开桌面应用 → 使用 ChatGPT 登录 → 选择模型和项目文件夹 → 生成步骤 → 审阅 → 执行 → 检查项目版本差异与测试。

后续评价：记录首次完成任务所需时间、执行失败后的恢复率、验收通过率与提供方报告的用量。上述是评价方案，当前没有真实用户样本或节省率。
