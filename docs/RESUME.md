## 面试可以解释的决策

- 用户的完整任务是：开发者和解决方案交付人员需要把目标交给执行工具，同时知道它执行了什么、结果能否验收。
- 核心流程是：选择项目文件夹 → 官方账户授权 → 选择模型 → 输入目标 → 生成步骤 → 审阅步骤 → 确认执行 → 检查项目差异与测试结果。
- 已有证据是：桌面窗口和安装后启动已经验证；核心 CLI 263 项测试通过，Windows/macOS/Linux 的 Node 20/22 检查通过。桌面执行器包含原生 Codex，打包检查实际调用其版本命令。
- 需要清楚说明：桌面版集成 Codex 执行器；原有 CLI 保留多适配器能力。固定示例不是实际 AI 执行，真实账户生成与项目修改仍待本人授权验收。运行比较要求目标一致、运行完整且有成功回执和测试证据；未知用量保持未知。

真实模型成功率、用户采用率、课堂效果、节省工时与成本没有测量数据，当前不写成业绩数字。263 项测试等数量仅描述测试覆盖，不代表用户效果。
